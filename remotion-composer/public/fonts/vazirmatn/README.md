# Vazirmatn — vendored Persian typeface (v3 opening hook)

Three static weights of [Vazirmatn](https://github.com/rastikerdar/vazirmatn) v33.003
by Saber Rastikerdar, licensed under the SIL Open Font License 1.1 (see `OFL.txt`).
They come unmodified from the release archive `vazirmatn-v33.003.zip` (`fonts/ttf/`).

Used only by the #387 v3 opening hook (Mehran's approved `Hook_v2_photo.html` design);
the v2 path and every other piece of text keep Estedad / Kahroba. Only the weights the
design uses are shipped, so Chrome never synthesizes a weight. The renderer loads them
from this folder, never from Google Fonts.
