# Phase card — idea

- **Inputs:** approved source/topic and requested delivery format.
- **Output:** schema-valid `brief` with mode, platform, duration, caption mode, hook strategy, subject, and typography budget.
- **Use:** pipeline manifest `idea.review_focus`; web search only when factual grounding is missing.
- **Success:** production profile is explicit; subject is camera-visible; beat count and footage feasibility fit the duration.
- **Stop:** unsupported facts, unclear production mode, or missing authority for copy. Record the blocker; do not invent.
- **Details on demand:** `idea-director.md`.
