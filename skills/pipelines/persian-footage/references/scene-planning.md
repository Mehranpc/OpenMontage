# Scene planning reference

Open only for active scene-plan diagnosis.

## Query design examples

Translate meaning into something a camera can record. Prefer concrete noun/action plus qualifier and optional shot type. For abstract attention, search visible behaviour (eyes scrolling, commuters on phones), not `attention is scarce`. For calm, search water ripple or resting hands, not `becoming calm`.

## Subject continuity

Generic health imagery can make a subject-specific video read as a medical montage. Keep the subject literal in first/last footage events and at least 40% overall. For study/mechanism beats, use honest co-presence where available rather than replacing the subject with labs, charts, or devices.

## Event quality

An event defines narration span, intended meaning, subject/action, affect, motif, composition, presence, importance, conflict visibility, fallback level, camera, scale/environment, and two queries. A query is not the event. Importance prioritizes the one bounded retry; it never expands budgets.

## Human judgement

The audit cannot prove a query is concrete, `shows_subject` is honest, a relationship direction is correct, or a Persian line stayed normalized. Review these explicitly and answer advisories in checkpoint metadata. If a third typographic fallback is needed or no honest visual event exists, send the brief upstream.
