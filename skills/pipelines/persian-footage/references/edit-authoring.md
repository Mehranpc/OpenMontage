# Edit authoring reference

Open only for a named edit-authoring problem. The compact execution contract remains `edit-director.md`.

## Moment structure

A moment is a grammatical phrase with ordered lead/hero/tail/source roles. Array order is Persian reading order. One hero carries the emphasis; spoken units stay attached (`۲۲۶۴ نفر`). Builds accumulate later reveal steps instead of replacing earlier facts. Every reveal step independently pays fixation, character, and block-landing cost.

`kind` is editorial metadata and selects the active Film Type ladder; it does not authorize arbitrary placement. Hook is opening-only and is either claim+qualifier or a flat display when no grammatical split exists. Do not invent claims, jeopardy, or a one-word label to solve geometry.

## Authority boundaries

Approved script owns delivered copy; timing provider owns only the clock. Exact copy is hash-locked; ordinary copy is normalized before persistence. Captions and moments have different jobs. Runtime derives burned cues and SRT from the same approved-script alignment.

Music has one owner: `persian.musicTrack`. Keep complete provenance and honest risk language; licence evidence cannot promise that third-party platform claims are impossible.

## Geometry and placement

Film Type sizes come from the three ladders and browser measurement in the active profile. Legacy ratios/anchor/accent/scrim recipes are not Film Type guidance. Current placement is selected against reviewed crop and conservative avoid regions. If no candidate fits, revise copy structure, crop, shot, placement window, or timing explicitly; do not weaken evidence.

## Timeline checks

Shots tile duration with no gaps/overlaps and retain event lineage. Moments anchor to current narration timings and are re-derived after any voice change. Opening moment begins within 0.6s. Editorial density/coverage/gaps remain bounded. Retention roles, subject regions, caption band, and moving brand schedule are reviewed together in preflight.

## Send-back scope

Copy authority failure → script/editorial decision. Missing/incorrect timing → alignment. Unusable media/crop/subject evidence → assets. No valid event mapping → scene plan. Profile/runtime/tool gap → structured blocker. Never reacquire or rewrite unrelated stages.
