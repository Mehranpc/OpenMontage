# Compose verification reference

Open this reference only for a compose verification or failure diagnosis. The core authority remains `compose-director.md`, `film-type.md`, `final-candidate-protocol.md`, and executable library contracts.

## Sampling plan

Sample every moment midpoint, final reveal midpoint for builds, every gap midpoint, burned-caption entry/mid/exit, opening gate, and each prepared Film Type brand slot. Boundary frames are animation states, not stable evidence. Save paths in `render_report`.

## Profile instruments

Film Type uses `verify_film_frames` with resolved props: prepared rect, 4.5:1 composite contrast, shadow presence, and composite result. It has no Legacy accent colour, scrim plateau, shared right anchor, or fixed watermark. Therefore reading order, colour-separated gap emptiness, and stack rhythm are visual `not_checked` items until inspected by a Persian reader.

Legacy uses `verify_frames`, `check_gap_is_empty`, `check_moment_arrangement`, `measure_stack_rhythm`, and watermark ablation. Scope ink to the moment's scrim plateau using `stackHeightPx`; never feed gap frames to moment measurement.

## Failure ownership

- sync refusal → re-run `retime_moments`; never nudge seconds.
- pacing equality at rounded boundary → reserialize from canonical timing; never add milliseconds manually.
- music refusal → repair the single `musicTrack` licence/risk record or deliberate-silence decision.
- fit refusal → edit copy/structure upstream; never shrink below profile ladders.
- no brand slot → adjust approved schedule/suppression; never alter footage or frozen sidecars for brand recovery.
- missing font/hang → verify bundled Estedad and that public dir was not overridden.
- missing media → repair selected asset path; never render black.
- unsupported profile hash → add explicit versioned support through a separate code PR.

## Known-invalid detector shortcuts

Do not implement brightness-only text or watermark masks, row-mean/per-column darkening, temporal invariance, profile correlation for glyph order, line-height arithmetic for ink gaps, centred-column symmetry, or Legacy accent detection on Film Type. Footage, codec ringing, font overhang, and moving brand schedules make these produce confident false results.

## Report evidence

Record numbers and missing coverage, not adjectives: resolved profile/hash, output digest, dimensions/duration, moment/caption counts, text coverage, sampled frame paths, worst contrast, rect/shadow/composite results, brand slot evidence, sync drift, reading floors, motion/luminance runs, caption frames, audio probe/mix, attributions, music provenance, warnings, and explicit `not_checked` items.

A green measurement run is not approval. `persian_text_verified` requires profile automation plus actual painted-frame review; final delivery additionally requires final review of the same digest and explicit human approval.
