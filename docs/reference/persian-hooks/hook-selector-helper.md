# Persian Hook Selector

## سیستم انتخاب بهترین Hook برای محتوای روان‌شناسی، علوم اعصاب و سبک زندگی

---

# ۱. قانون اصلی

قبل از نوشتن Hook فقط به «موضوع» نگاه نکن.

اول مشخص کن **چه چیزی در دست داری:**

1. مطالعهٔ جدید
2. آزمایش / RCT / مداخله
3. مطالعهٔ همبستگی
4. آمار یا عدد عجیب
5. مطالعهٔ مغز / علوم اعصاب
6. مرور سیستماتیک / متاآنالیز
7. راهنما یا توصیهٔ علمی
8. توضیح یک رفتار روان‌شناختی
9. Myth Busting
10. راهکار عملی
11. داستان یا تجربه
12. هشدار / ریسک

بعد Topic Modifier را اضافه کن:

* ADHD
* اضطراب
* افسردگی
* خواب
* حافظه
* تمرکز
* مغز
* اهمال‌کاری
* انگیزه
* موفقیت
* روابط
* والدگری
* سالمندی
* تغذیه / ورزش / سبک زندگی

# ۲. امتیازدهی Hook قبل از استفاده

هر Hook را از ۱۰ امتیاز بسنج.

### A. ارتباط شخصی — ۰ تا ۲

آیا مخاطب سریع می‌فهمد «این به من مربوط است»؟

### B. شکاف اطلاعاتی — ۰ تا ۲

آیا سؤال یا اطلاعات ناتمامی ایجاد شده که مخاطب جوابش را می‌خواهد؟

### C. مشخص بودن — ۰ تا ۲

آیا Hook به‌جای حرف کلی، رفتار، عدد، موقعیت یا نتیجه مشخص دارد؟

### D. تضاد / تازگی — ۰ تا ۲

آیا چیزی خلاف انتظار یا تازه در جمله وجود دارد؟

### E. تطابق با محتوا — ۰ تا ۲

آیا ویدیو واقعاً چیزی را که Hook وعده می‌دهد تحویل می‌دهد؟

**هدف:** حداقل ۷/۱۰.

اگر **E کمتر از ۲** است، Hook را رد کن حتی اگر بسیار جذاب باشد.

# ۳. Selector سریع

| ورودی              | خانواده‌های Hook مناسب                      |
| ------------------ | ------------------------------------------- |
| نتیجهٔ عجیب مطالعه | Result First + Surprise + Open Loop         |
| RCT / آزمایش       | Experiment + Contrast + Result First        |
| تحقیق همبستگی      | Pattern + Question + Association            |
| عدد عجیب           | Number First + Scale + Comparison           |
| ADHD               | Recognition + Self-Relevance + Myth Bust    |
| اضطراب             | Familiar Moment + Why + Hidden Mechanism    |
| افسردگی            | Recognition + Nuance + Hidden Symptom       |
| خواب               | Familiar Problem + Hidden Cause + Practical |
| مغز                | Question + Mechanism + Counterintuitive     |
| اهمال‌کاری         | Self-Relevance + Myth Bust + Friction       |
| موفقیت             | Contrarian + Mistake + Simple Change        |
| مرور علمی          | Consensus + Number + Myth Correction        |
| راهکار عملی        | Problem → Simple Change → Benefit           |
| هشدار سلامت        | Specific Risk + Context + Limitation        |

# ۴. سیستم Topic Modifier

بعد از انتخاب Hook پایه، موضوع را روی آن سوار کن.

## ADHD

از واژه‌های:

* شروع کردن
* زمان
* توجه
* حواس‌پرتی
* پاداش
* کار خسته‌کننده
* فشار زمانی

استفاده کن.

## اضطراب

از:

* «بعد از مکالمه»
* «در جمع»
* «قبل از اتفاق»
* «بدترین سناریو»
* «نگاه دیگران»
* «حالت هشدار»

استفاده کن.

## خواب

از:

* «وقتی سرت رو روی بالش می‌ذاری»
* «صبح که بیدار می‌شی»
* «آخر شب»
* «بعدازظهر»
* «ساعت بدن»

استفاده کن.

## اهمال‌کاری

از:

* «می‌دونی باید انجامش بدی، ولی...»
* «شروع کردن»
* «لحظه آخر»
* «منتظر انگیزه»
* «کار پنج دقیقه‌ای»

استفاده کن.

این‌ها Hook را از حالت **موضوع عمومی** به **تجربهٔ زیستهٔ مخاطب** تبدیل می‌کنند.

# ۵. فرمول دو مرحله‌ای بسیار مؤثر

Hook لازم نیست تمام کار را در یک جمله انجام دهد.

### جمله ۱: Stop

### جمله ۲: Lock

مثال:

**Stop:**
«بزرگ‌ترین اشتباه دربارهٔ اهمال‌کاری اینه که فکر کنیم همیشه از تنبلی میاد.»

**Lock:**
«گاهی چیزی که جلوی شروع رو گرفته، نه انگیزه، بلکه نحوه‌ایه که مغز هزینهٔ شروع کار رو ارزیابی می‌کنه.»

---

### مثال مطالعه

**Stop:**
«نتیجهٔ این آزمایش دقیقاً چیزی نبود که انتظار داشتن.»

**Lock:**
«گروهی که `[مداخله]` رو دریافت کرده بود، در `[نتیجه]` تفاوت قابل‌اندازه‌گیری نشون داد.»

---

### مثال اضطراب

**Stop:**
«چرا بعد از یک مکالمه ساده ساعت‌ها حرف‌هات رو مرور می‌کنی؟»

**Lock:**
«این رفتار می‌تونه با حساسیت بیشتر ذهن به ارزیابی اجتماعی ارتباط داشته باشه.»

# ۶. الگوریتم انتخاب از بین چند Hook

اگر ۱۰ Hook داری، این ترتیب را اجرا کن:

### مرحله ۱ — حذف دروغ

هر Hook که claim مقاله را بزرگ‌تر می‌کند → حذف.

### مرحله ۲ — حذف کلی‌گویی

«یک مطالعه جالب...»
«دانشمندان کشف کردند...»
«آیا می‌دانستید...»

اگر نسخه مشخص‌تر وجود دارد → حذف.

### مرحله ۳ — Self-Relevance

اگر یافته قابل ربط دادن به تجربهٔ روزمره است، نسخهٔ self-relevant امتیاز اضافه بگیرد.

### مرحله ۴ — Specificity

عدد، رفتار، موقعیت یا نتیجهٔ واقعی → امتیاز اضافه.

### مرحله ۵ — Surprise

اگر واقعاً نتیجه خلاف انتظار است، آن را جلو بیاور.

### مرحله ۶ — Payoff

Hookی انتخاب شود که بتوانی در **جملهٔ دوم یا سوم** شروع به تحویل وعده‌اش کنی.

# ۷. چهار سطح شدت Hook

برای جلوگیری از clickbait، شدت را با قدرت یافته هماهنگ کن.

### Level 1 — آرام

برای یافته‌های محدود:

> یک مطالعهٔ جدید دربارهٔ `[موضوع]` یک ارتباط جالب پیدا کرده.

### Level 2 — جذاب

برای یافتهٔ نسبتاً قوی:

> پژوهشگرا `[X]` رو بررسی کردن و نتیجه جالب بود.

### Level 3 — قوی

برای یافتهٔ واقعاً غیرمنتظره:

> نتیجه دقیقاً برعکس چیزی بود که انتظار داشتن.

### Level 4 — بسیار قوی

فقط وقتی داده واقعاً آن را توجیه می‌کند:

> `[عدد٪]` تفاوت؛ و این فقط با `[عامل]` همراه بود.

**Level 4 نباید انتخاب پیش‌فرض باشد.**

# ۹. Pattern Interrupt فارسی

برای تنوع گاه‌به‌گاه:

* «صبر کن...»
* «اما یه نکته هست.»
* «نه، داستان این نیست.»
* «اینجاش عجیب می‌شه.»
* «حالا قسمت مهمش...»
* «اما چرا؟»
* «یه لحظه فکر کن...»
* «این عدد رو ببین.»
* «تفاوت فقط همین بود.»
* «مشکل دقیقاً همین‌جاست.»

این‌ها باید **کمکی** باشند، نه خود Hook.

ضعیف:

> «صبر کن!»

قوی:

> «صبر کن؛ قبل از اینکه بی‌انگیزگی رو به تنبلی ربط بدی، اینو بدون.»

# ۱۰. ۱۰ Master Template پیشنهادی

اگر فقط ۱۰ فرمول بخوای نگه داری:

### ۱

`اگر [تجربه آشنا]، شاید دلیلش چیزی نباشه که فکر می‌کنی.`

### ۲

`نتیجهٔ [مطالعه/آزمایش] برعکس چیزی بود که انتظار داشتن.`

### ۳

`بزرگ‌ترین اشتباه دربارهٔ [موضوع] اینه که [باور].`

### ۴

`چرا وقتی [موقعیت]، [رفتار عجیب] می‌کنیم؟`

### ۵

`[عدد/نتیجه]؛ اما بخش مهم ماجرا دلیل پشتشه.`

### ۶

`پژوهشگرا فقط [X] رو تغییر دادن؛ بعد [Y] اتفاق افتاد.`

### ۷

`چیزی که شبیه [برداشت منفی] دیده می‌شه، همیشه [برداشت] نیست.`

### ۸

`اگر می‌خوای [نتیجه]، اول این یک چیز رو بررسی کن.`

### ۹

`همه روی [X] تمرکز می‌کنن؛ اما [Y] هم مهمه.`

### ۱۰

`این تحقیق علت رو ثابت نمی‌کنه؛ اما یک رابطهٔ جالب پیدا کرده.`

# ۱۱. Hook Contract

هر Hook باید این قرارداد را رعایت کند:

**Hook:** سؤال ایجاد کن.
**جملهٔ ۲:** زمینه بده.
**جملهٔ ۳:** اولین payoff را تحویل بده.
**ادامه:** پاسخ را توسعه بده.

نباید:

**Hook:** «نتیجه باورنکردنی!»
↓
۱۰ ثانیه مقدمه
↓
۱۵ ثانیه تاریخچه
↓
بالاخره نتیجه.

مخاطب برای دریافت payoff نباید بیش از حد منتظر بماند.

# ۱۲. فرمول نهایی مخصوص محتوای علمی فارسی

برای اکثر ریلزهای علمی:

## 1. Hook

**Self relevance یا Surprise**

↓

## 2. Evidence

«یک مطالعه روی `[N]` نفر...»

↓

## 3. Result

یافتهٔ اصلی

↓

## 4. Meaning

این برای مخاطب چه معنایی دارد؟

↓

## 5. Limitation

یک «اما و اگر» کوتاه

↓

## 6. Takeaway

نتیجه‌ای که مخاطب باید با خودش ببرد.

# مثال کامل

موضوع:
مطالعه‌ای دربارهٔ بازی‌های ویدیویی و توانایی شناختی.

### Hook ضعیف

«آیا بازی‌های ویدیویی برای مغز خوب هستند؟»

### بهتر

«بزرگ‌ترین اشتباه دربارهٔ بازی‌های ویدیویی اینه که فکر کنیم فقط وقت تلف کردنه.»

### قوی‌تر، اگر منبع اجازه دهد

«حتی وقتی پژوهشگرا خودشون به افراد بازی دادن، بعضی توانایی‌های ذهنی بهتر شد.»

### ادامه

«و نکتهٔ جالب اینه که فقط دربارهٔ بازی‌های مخصوص تقویت مغز حرف نمی‌زنیم...»

# تست ۵ ثانیه‌ای قبل از انتشار

قبل از تأیید Hook از خودت بپرس:

**۱. مخاطب در ۲ ثانیه اول می‌فهمه موضوع چیه؟**

**۲. دلیل مشخصی داره که جملهٔ بعد رو بشنوه؟**

**۳. چیزی در جمله شخصی، تازه، متناقض یا مشخص هست؟**

**۴. خود مقاله دقیقاً از ادعا حمایت می‌کنه؟**

**۵. آیا می‌تونم وعدهٔ Hook رو سریع تحویل بدم؟**

اگر جواب یکی از **۲، ۴ یا ۵** «نه» باشد، Hook را بازنویسی کن.

# اصل نهایی

بهترین Hook لزوماً هیجان‌انگیزترین جمله نیست.

بهترین Hook جمله‌ای است که هم‌زمان:

**Scroll را متوقف کند**
+
**مخاطب درست را شناسایی کند**
+
**یک سؤال باز بسازد**
+
**وعدهٔ مشخص بدهد**
+
**و محتوای بعدی واقعاً آن وعده را تحویل دهد.**
